# Data

All paths are defined in `src/config.py`. Large source data and generated splits are **gitignored**. Only the small demo samples and `insights.json` are committed.

```
data/
├── raw/                      gitignored · source datasets, as downloaded
│   ├── aptos/<class>/          APTOS 2019, 3,662 images (224×224 PNG)
│   └── eyepacs/
│       ├── images/             EyePACS, 35,108 images (~1024px JPEG, e.g. 10_left.jpeg)
│       └── trainLabels.csv     image,level  (level = 0–4 grade)
├── splits/                   gitignored · generated by scripts/build_combined.py
│   ├── aptos_train/<class>/    APTOS training images (links into raw/aptos)
│   ├── aptos_test/<class>/     APTOS held-out test set
│   ├── eyepacs_train/<class>/  EyePACS training sample (resized to 224×224)
│   ├── eyepacs_test/<class>/   EyePACS held-out test set (resized to 224×224)
│   ├── mixed_train/<class>/    aptos_train + eyepacs_train → trains the deployed model
│   └── split_manifest.csv      source,image,label,split for every image
├── samples/                  committed · small demo sets
│   ├── train/<class>/          50 APTOS images per class
│   └── test/<class>/           15 APTOS images per class
├── insights.json             committed · cached data for the UI Visualizations tab
├── uploads/                  runtime · images uploaded for retraining (gitignored)
└── uploads.db                runtime · SQLite record of uploads + retrain runs (gitignored)
```

Class folders are `No_DR` (0), `Mild` (1), `Moderate` (2), `Severe` (3), `Proliferate_DR` (4).

## How the splits were made

`python scripts/build_combined.py` (seed 42, deterministic: rerunning it rebuilds the exact same split).

- **APTOS:** for each class, a random 15 % is held out as `aptos_test`. All remaining images go to `aptos_train`.
- **EyePACS:** each patient has a left and a right eye image (`10_left`, `10_right`). The two are very similar, so **patients** are split 85/15 first, and a patient's eyes never end up on different sides. Then up to 400 images per class are sampled for `eyepacs_train` and 60 per class for `eyepacs_test`. EyePACS is 73 % No_DR, so the cap keeps it from swamping the other grades.

| Split | No_DR | Mild | Moderate | Severe | Proliferate_DR | Total |
|-------|------:|-----:|---------:|-------:|---------------:|------:|
| `aptos_train` | 1,534 | 314 | 849 | 164 | 251 | 3,112 |
| `aptos_test` | 271 | 56 | 150 | 29 | 44 | **550** |
| `eyepacs_train` | 400 | 400 | 400 | 400 | 400 | 2,000 |
| `eyepacs_test` | 60 | 60 | 60 | 60 | 60 | **300** |
| `mixed_train` | 1,934 | 714 | 1,249 | 564 | 651 | 5,112 |

Checked when built: no image appears in both a training and a test folder, and no EyePACS patient appears in both `eyepacs_train` and `eyepacs_test`.

## How each dataset was used

| Data | Used for |
|------|----------|
| `splits/mixed_train` | Training the **deployed model**. `train_model.py` holds out 20 % of it for validation (early stopping). |
| `splits/aptos_train` | Training the APTOS-only comparison models. |
| `splits/aptos_test` | **Main reported test score.** Never used for training, validation or model selection. |
| `splits/eyepacs_test` | Second test score: how the model does on photos from other cameras and clinics. |
| `samples/train` | UI **Visualizations** charts (`insights.json`), smoke test, Locust. |
| `samples/test` | Quick demo images for the **Predict** tab and Locust load tests. |
| `raw/eyepacs` (rest) | Not used. About 33,000 EyePACS images remain available for future experiments. |

> ⚠️ `samples/test` is **not** a held-out test set. Its images were sampled from all of APTOS and overlap the training data. Use `splits/aptos_test` and `splits/eyepacs_test` for any reported metric.

## Getting the source data

- **APTOS:** `python scripts/download_data.py` downloads `bumbledeep/aptos` (Hugging Face) into `raw/aptos/` and refreshes `samples/`.
- **EyePACS:** download it manually from Kaggle's 2015 *Diabetic Retinopathy Detection* competition (needs an account). Put the images in `raw/eyepacs/images/` and `trainLabels.csv` in `raw/eyepacs/`. Then run `python scripts/build_combined.py`.
